Before you start

A few useful checks that do not require changing router settings.

  • Check that the router is powered on and its internet/WAN light looks normal.
  • Try opening the same website on another device to see whether the issue affects one device or the whole network.
  • If the signal is weak, move closer to the router and test again.

Wi-Fi Hub only shows live status or performs router actions when a compatible connection is configured. It will not invent device counts or claim a router action succeeded when it has not.
