Router power, restart, and Wi-Fi troubleshooting

Router appears offline

  1. Check the power adapter and wall socket. Inspect the router power light.
  2. Check that the Ethernet/fibre/ONT cable is firmly seated and that the provider service is active.
  3. Restart safely: use the router's power button if provided, or unplug power for 30 seconds, reconnect it, then wait 3–5 minutes. Do not press the factory-reset pinhole unless you intend to erase settings.
  4. Reconnect your phone/laptop and test one website. If all devices remain offline, contact your ISP.

Wi-Fi is on but internet is unavailable

  1. Check whether the router WAN/Internet indicator is red or off.
  2. Test another device and forget/rejoin the Wi-Fi network if needed.
  3. Check ISP outage/payment status and modem/ONT indicators.

Turning Wi-Fi off/on remotely

Use the router's official app or admin page unless a compatible API is configured. Wi-Fi Hub must not show success unless a supported integration confirms the command. Never share the router admin password in chat or source code.

Smart Switch / ESP relay

  1. Confirm the ESP board is powered and connected to the expected network.
  2. Confirm the relay wiring and active-high/active-low logic before connecting a load.
  3. Test a low-voltage indicator/load first. Do not work on mains wiring while powered; get a qualified electrician.
  4. Remote access requires an authenticated backend or secure device protocol. A public HTTPS page cannot directly call arbitrary local HTTP endpoints because browsers block mixed content.

Important limitations

  • Wi-Fi Hub cannot control every router model. Restart or Wi-Fi on/off needs a compatible router API or backend integration.
  • Bluetooth tools need a supported browser, Bluetooth hardware, and your permission. Web Bluetooth support varies by device.
  • Theme preferences are stored in this browser. Clearing site data may remove them.
  • Never share your router admin password or Firebase secrets in public pages or screenshots.
